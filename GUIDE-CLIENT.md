# Guide de l'espace agence — Humo Kolwezi

Ce guide s'adresse a la personne qui gere le site au quotidien, sans
connaissance technique. Gardez-le a portee de main.

---

## 1. Se connecter

1. Ouvrez `https://votre-domaine.cd/admin/login`.
2. Entrez votre e-mail et votre mot de passe.
3. La premiere fois, le site vous demande d'activer la double
   authentification (un code de securite a six chiffres) :
   - installez l'application **Google Authenticator** ou **2FAS** sur votre
     telephone (gratuites, sur Play Store ou App Store) ;
   - scannez le QR code affiche a l'ecran avec l'application ;
   - recopiez le code a six chiffres qu'elle affiche dans le champ demande ;
   - **notez les huit codes de secours** qui s'affichent ensuite, sur papier,
     et rangez-les en lieu sur. Ils ne seront plus jamais affiches. Ils vous
     serviront uniquement si vous perdez votre telephone.
4. Aux connexions suivantes, le site vous demande votre mot de passe puis le
   code a six chiffres affiche par l'application sur votre telephone.

**Si vous bloquez cinq fois de suite**, le site vous demande d'attendre
quinze minutes avant de reessayer. C'est normal, c'est une protection contre
le piratage.

---

## 2. Remplacer les photos d'un bien deja en ligne

1. Depuis le tableau de bord, trouvez le bien dans le tableau et cliquez sur
   **Editer**.
2. Descendez jusqu'au bloc **Photos**. Vous voyez deux zones :
   - **Photos actuelles** : chaque photo a un bouton rouge **Supprimer**.
     Cliquez dessus pour retirer une photo qui ne convient plus. La photo
     n'est pas encore supprimee du site a cet instant — c'est juste retire de
     l'apercu.
   - **Ajouter de nouvelles photos** : cliquez sur **Ajouter une photo**,
     puis **Choisir une photo sur l'appareil** pour selectionner un fichier
     sur votre telephone ou votre ordinateur. Remplissez la case
     **Description de la photo** (par exemple : « Facade de la maison vue de
     la rue ») : c'est ce qui s'affiche si l'image ne charge pas, et c'est
     aussi ce qui aide Google a comprendre ce que montre la photo.
3. Repetez pour chaque photo a remplacer.
4. **Cliquez sur « Enregistrer les modifications » en bas de page.** C'est
   seulement a ce moment que les anciennes photos disparaissent du site et
   que les nouvelles apparaissent. Rien n'est perdu avant ce clic — vous
   pouvez fermer la page sans rien casser si vous changez d'avis.

**Formats acceptes** : JPEG, PNG, WebP ou AVIF (les photos prises avec un
telephone recent sont presque toujours dans un de ces formats). Taille
maximale : 5 Mo par photo. Un bien peut avoir jusqu'a douze photos.

---

## 3. Ajouter un nouveau bien

1. Depuis le tableau de bord, cliquez sur **Ajouter un bien** en haut a
   droite.
2. Remplissez le titre, la categorie (maison, parcelle ou vehicule), le
   statut, le prix en dollars et le quartier.
3. Ecrivez une description : plus elle est precise (surface, nombre de
   pieces, etat de l'eau et de l'electricite, quartier), plus elle rassure un
   acheteur.
4. Ajoutez au moins une photo, avec sa description (voir section 2).
5. Cochez **Mettre en vedette sur la page d'accueil** si vous voulez que ce
   bien apparaisse dans la selection du moment.
6. Cliquez sur **Publier le bien**. Il apparait immediatement dans le
   catalogue public.

---

## 4. Retirer un bien du site

Deux options selon le cas :

- **Le bien est vendu** : dans le tableau de bord, cliquez sur
  **Marquer vendu** sur la ligne du bien. Il reste visible sur le site avec
  l'etiquette « Vendu » (utile pour montrer votre activite), mais il sort du
  catalogue des biens disponibles.
- **Le bien doit disparaitre completement** : cliquez sur **Supprimer**.
  Une fenetre de confirmation s'affiche, car cette action est definitive.
  Une fois confirmee, la fiche et ses photos ne sont plus recuperables.

---

## 5. Les messages recus

Chaque fois qu'un visiteur remplit le formulaire de contact, un message
apparait dans **Messages**. Vous pouvez :
- repondre directement sur WhatsApp en cliquant sur **Repondre sur
  WhatsApp** ;
- marquer le message comme lu une fois traite ;
- le supprimer s'il n'est plus utile.

---

## 6. Les avis clients, la FAQ et les etudes de cas

Ces trois sections fonctionnent de la meme maniere : un formulaire pour
ajouter, un bouton pour publier ou masquer, un bouton pour supprimer.

- **Avis clients** (`/admin/temoignages`) : n'ajoutez un avis qu'avec
  l'accord de la personne citee.
- **Questions frequentes** (`/admin/faq`) : utile pour repondre a l'avance
  aux questions les plus courantes (frais, delais, paiement).
- **Etudes de cas** (`/admin/etudes-de-cas`) : racontez une vente reelle en
  trois temps (la situation de depart, ce que vous avez fait, le resultat).
  C'est ce qui convainc le mieux un vendeur hesitant. Utilisez une initiale
  pour le nom du client (« Famille K. ») sauf accord ecrit pour utiliser son
  nom complet.

---

## 7. Bon reflexe general

Rien n'est jamais applique tant que vous n'avez pas clique sur le bouton
d'enregistrement de la page (« Enregistrer », « Publier », « Ajouter »).
Vous pouvez donc explorer sans crainte : si vous fermez la page sans valider,
rien n'a change sur le site public.
